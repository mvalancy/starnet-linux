# StarNet v0.12.5

Workflow lines you can step-test and start from a folder or webhook, Google Workspace early access, steadier long runs, and a large security update. Heads-up: metered runs now stop once spend in the last 24 hours reaches $25, until you press RESUME in Budget (editable; 0 turns it off). Some plugins, chat-channel bots and code.run ask for approval or pairing again. The heads-up items at the end list what to check.

- Workflow studio: the Workflow panel docks beside the station and shows each agent's portrait. Step-test a line one stage at a time (pause, continue, edit the hand-off, rerun or rewind). One agent can crew several bays, and a line's INBOX can work in a trusted project folder.
- Line triggers: a file dropped in a watched folder, or a call to the line's webhook, starts one run of that line. Bay lamps, a crate inspect card, per-line INBOX plates and a TODAY row show what each line did. Build mode lists workflow machines on a MACHINES shelf and warns before a placement connects to machines already on the floor.
- Routines can be renamed and edited in Automation. A failed routine re-arms in local time instead of UTC, and undelivered results are retried during the session instead of only at the next launch.
- Google Workspace early access: Gmail (full or send-only), Calendar, Docs, Sheets and Drive can be connected before Google finishes verifying StarNet. Google shows an unverified-app warning at sign-in and limits unverified apps to 100 users. Gmail and Drive tool results are never sent to StarNet Managed models.
- COMMS shows when a model call is slow or retrying, and why. The local /v1 endpoint keeps long streaming replies alive. Setup errors say what is actually missing instead of "No model is connected yet": Grok not signed in, a missing API key, model or base URL, a key the provider rejected, or an account with no credits.
- Reasoning levels: Grok (xAI), OpenAI API and DeepSeek models offer the levels each model accepts, read from xAI's and DeepSeek's model lists and OpenAI's documentation, instead of showing OFF while the model ran at its own default. StarNet Managed models that support reasoning offer levels too. DeepSeek models in thinking mode no longer fail on their second request, and GPT-5.6 through the OpenAI API runs with reasoning off because that API cannot combine its reasoning with tools.
- Steadier long runs: conversations are saved turn by turn, so interrupted runs appear in history and can be continued. Recovery from provider outages, stalled models, context overflow and cut-off tool calls is better. Stop also stops the helpers a run started, and restoring a checkpoint can be undone.
- Spend safety: the daily limit counts metered runs only (API keys and credits). A loop whose passes change nothing pauses after three in a row, and unattended runs that repeat the same failing calls or stop making progress end and say why.
- Coding tools: ambiguous edits are refused instead of guessed, files can be read with line numbers, search respects .gitignore and uses ripgrep when installed, and commands may run for up to 10 minutes. On Windows, commands report their real exit code (earlier versions reported 0 for every command) and a cd carries over to the next command.
- Smaller requests: skill recipes, the station manual's reference sections and large connector tool sets load on demand, and tool-output limits scale with the model's context window.
- Agents can edit a crew member's Dossier documents from chat. Each edit asks for approval, is scanned, and is read back before it counts as saved. Lessons learned inside a project are recalled only in that project.
- A DaVinci Resolve edit bay on the STUDIO prop (live control needs Resolve Studio). Seven hosted MCP connectors join the catalog: Corpus (US law), Financial Datasets, You.com, XMemo, Replaid, Markifact and Adspirer.
- Fourteen new agent skins (51 in all). Agents move more fluidly through corners and between poses.
- Desktop: a new app icon, and media ships as one copy, so the Windows installer is about 40% smaller (382 MB, down from 640 MB). On Windows, StarNet stops drawing the station while minimized or in the tray and recovers from a WebView2 crash instead of showing a white screen. Opening StarNet again while it is starting no longer quits it, slow starts get up to 60 seconds, and macOS shows a notice if the local engine cannot start.
- A false graphics check could keep a session on the slow CPU rendering path; it now stays on the GPU.
- Fixes: Opus 5.5 and Gemini thinking settings work and Gemini shows its full model list. Resuming a saved station keeps the provider you selected. A specialist set to Follow station default now runs on the Overseer's model and provider in COMMS, workflow lines, RUN A SAMPLE and chat channels, and choosing a provider in Settings moves the station default with it, so BYOK stations are no longer refused with "Out of managed credit" (#24). A command or routine that runs a script is no longer refused as a desktop-app launch because the script contains a word like write (#50). E-STOP also stops a RUN A SAMPLE job.
- Security: web tools and connector sign-ins connect only to the address that passed the safety check, symlinks cannot escape a workspace, and code.run runs model code in an isolated worker under Node's permission model. The API token no longer appears in links, file URLs or event streams, the desktop window loads only the app itself under a strict content security policy, and the local server refuses other hosts and framing by other sites.
- Security: webhook and watched-folder payloads, forwarded messages and chat-channel attachments stay marked untrusted through helpers, resumed conversations and hand-offs. Keys and tokens StarNet holds, including masked key fragments echoed in provider errors, are redacted from logs and diagnostics, and helper processes no longer inherit them. Credential files are private to your user on macOS, Slack and Matrix bot tokens move to the OS keychain on desktop, and a ChatGPT sign-out survives a restart.
- Heads-up: the $25 daily limit also applies to stations that never set one. If your metered spend runs higher, raise it or set it to 0 in Budget. A routine the limit stops five times in a row pauses; re-enable it from ROUTINES after raising the limit.
- Heads-up: code.run now asks for approval like a shell command. Unattended runs can use it only on a Full Access agent.
- Heads-up: an agent whose name gave it the same id as one of StarNet's own folders (for example an agent named Codex, Grok, Kimi, Channels, Connectors or Plugins) can no longer use files or run commands. Recruit a replacement; it gets a safe id such as codex-2. The old agent's routines and notes do not move over automatically.
- Heads-up: installed plugins ask for approval once more, because approval now covers every file in the plugin's folder. A plugin with links inside its folder is refused, and one whose files change while it runs is turned off until you approve it again.
- Heads-up for chat channels: a Discord, Slack, Matrix or Signal bot with no paired owner needs the pairing code from its CHANNELS card; owners already paired keep working. Only the owner can use control commands, Full Access applies only in the owner's direct messages, and messages with attachments or forwarded text run without Full Access.
- Heads-up for Windows: commands now report failures that earlier versions hid, so routines and checks that looked green may show real failures.
- Heads-up for reasoning levels: an upgraded station keeps the reasoning its agents actually ran with in 0.12.4, even though 0.12.4 showed these models as OFF: the model's own default on OpenAI API, xAI and DeepSeek, and none on StarNet Managed. Pick a level in the model dock to change it; a higher level uses more tokens or credits.
- Rolling back to 0.12.4 means entering Slack and Matrix bot tokens again.

Release validation: the release candidate passed the full automated suite (952 fast and 155 HTTP steps), the adversarial API sweep, UI screenshot and golden-frame checks, the behavioral truth audit, interactive and customer journeys, the first-run check and the desktop shell’s Rust tests, plus the Linux release gate in CI. Signed Windows and notarized macOS (Apple Silicon and Intel) builds passed; an Intel Mac installed and restarted the app, and a hosted Windows machine installed the signed candidate on a clean system and over a populated v0.12.4 station with its data preserved. Real-account sign-in and a 48-hour installed soak were not performed; the owner waived the soak for this release. Public automatic-update delivery is verified after publication.
